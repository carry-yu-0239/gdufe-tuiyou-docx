# 推优入党综合考察表填写工具

> 微信小程序版已迁移完成：项目根目录可直接导入微信开发者工具，详见 [微信小程序说明](微信小程序说明.md)。原纯静态网页源码继续保留在 `src/` 作为回溯版本。

[打开在线填写工具](https://carry-yu-0239.github.io/gdufe-tuiyou-docx/)

适用材料：广东财经大学大数据与人工智能学院2026—2027学年度第一学期推优入党综合考察表。审核口径截至2026年10月13日。此工具辅助填写，不代替学院审核。

用户在网页填写真实资料，浏览器在学院原始DOCX模板中定点修改OOXML，生成可编辑的Word文件。保留主表、合并单元格、字体字号、边框及页边距；支持照片、电子签名、资格与填写校验，以及私密草稿导出恢复。

填写资料、照片、签名和页数核验PDF只在用户浏览器内处理。网站没有后端、登录、统计脚本或提交接口；GitHub Pages仅提供静态工具文件。保存的JSON草稿包含个人资料和图片，应妥善保管，不要提交到本仓库。

## 使用

1. 按8个步骤填写资料，核对佐证。
2. 校验通过后下载DOCX校对稿，在实际Word/WPS环境中打开检查。
3. 导出PDF，回到网页确认严格2页且内容完整，下载内容相同的DOCX提交稿。

纯浏览器无法保证Word在所有字体、软件环境下恰好分页为2页；字数限制仅用于降低溢出风险。原始空白模板在此前LibreOffice检查中为3页，因此最终页数要求由实际使用环境导出的PDF核验，不能将字数估算当成已满足2页。佐证真实性与PDF属于当前校对稿仍需实际人员核对。

## GitHub Actions 与 Pages

`.github/workflows/pages.yml` 在推送到 `main` 或手动触发时执行：

1. 获取代码；
2. 使用Python标准库将源码打包为完整离线HTML；
3. 上传 `dist/` 为GitHub Pages artifact；
4. 发布到 `github-pages` environment。

Pages发布来源为 **GitHub Actions**；HTTPS已开启。工作流仅使用必要的 `contents: read`、`pages: write`、`id-token: write` 权限，官方Actions固定提交SHA，不需要自定义密钥。仅推送到 `main` 的版本能自动发布。

本机重新打包：

```sh
python scripts/build_site.py
```

直接打开 `dist/index.html` 可离线使用。维护代码在 `src/`；修改源码后推送到 `main` 即可自动重新构建和发布，不需手动改已打包HTML。
